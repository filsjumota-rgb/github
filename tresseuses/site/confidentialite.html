Politique de confidentialité

Dernière mise à jour : 26 novembre 2026

Cette page explique quelles informations nous enregistrons, pourquoi, qui peut les voir et comment les supprimer.

1. Ce que nous enregistrons

Pour les tresseuses qui créent un profil :

  • l'adresse e-mail et le mot de passe du compte (le mot de passe est chiffré et nous ne pouvons pas le lire) ;
  • les informations du profil : nom affiché, ville, quartier, numéro WhatsApp, années d'expérience, disponibilités, présentation, styles et prix ;
  • les photos de réalisations ajoutées.

Pour les clientes qui laissent un avis : le prénom indiqué, la note et le commentaire. Aucun compte n'est nécessaire.

Statistiques : quand quelqu'un consulte un profil ou touche « WhatsApp » ou « Appeler », nous enregistrons seulement le type d'action, le profil concerné et la date. Nous ne conservons ni le nom ni le numéro de la personne qui consulte.

2. Ce qui est public

Le but de l'annuaire est d'être vu. Sont donc visibles par tous les visiteurs : les informations du profil (y compris le numéro WhatsApp), les photos, ainsi que les avis avec le prénom de leur auteur.

Ne sont pas publics : l'adresse e-mail des tresseuses et les statistiques. Chaque tresseuse ne voit que ses propres statistiques.

3. Pourquoi

  • Afficher l'annuaire et permettre aux clientes de contacter les tresseuses.
  • Permettre à chaque tresseuse de modifier son profil.
  • Montrer à chaque tresseuse combien de personnes ont consulté son profil.

Nous ne vendons pas ces informations et nous ne les utilisons pas pour de la publicité.

4. Où sont stockées les données

Les données sont hébergées par Supabase, sur des serveurs situés dans l'Union européenne (Irlande). Le site lui-même est hébergé par GitHub Pages. Ces prestataires techniques n'utilisent pas vos données pour leur propre compte.

Sur votre téléphone, le site garde seulement de petites informations pratiques : le fait que vous avez déjà laissé un avis à une tresseuse, ou déjà consulté un profil pendant votre visite. Il n'y a pas de cookie publicitaire.

5. Durée de conservation

Les informations d'un profil sont conservées tant que le profil existe. Quand une tresseuse retire son profil, ses photos, les avis reçus et ses statistiques sont supprimés.

6. Vos droits

Vous pouvez à tout moment consulter, corriger ou supprimer vos informations :

  • Tresseuses : depuis l'espace « Je suis tresseuse » (« Mettre à jour mon profil » ou « Retirer mon profil ») ;
  • Clientes : pour faire retirer un avis que vous avez laissé, contactez-nous.
